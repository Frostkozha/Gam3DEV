# Neon Dash

Three.js 3-lane runner playable ad (~40 s). Swipe or tap left/right to change lanes, swipe up to jump low cyan barriers, dodge tall pink blocks, grab coins, reach the gold finish gate. 3 lives. Keys: arrows / WASD / space.

```bash
npm install
npm run dev     # http://localhost:5177
npm run build   # dist/index.html, single file
```
